# 경제 개편 계획: 부족 · 자원 한도 · 자원 조정

> 상태: 0~2·5·6단계 끝. 무역(3·4·8단계)은 없앴다. 단계마다 끝나면 이 문서의 체크를 갱신한다.
> 수치는 모두 시작값이다. 단계마다 AI끼리 붙여 (부족별 승률, 10분 시점 자원·병력) 맞춘다.

## 0. 목표

- **지금의 문제**: 초원-숲은 초반 핵심 자원인 식량·목재가 함께 많아 빨리 커지고, 그 병력으로 설원·사막을 치면 끝난다.
  무역할 이유도, 설원·사막을 고를 이유도 없다.
- **고치는 방향**
  1. 자원지를 줄이고, 목재와 석재를 비슷하게 쓰게 한다 → 어디서나 무언가 모자란다.
  2. 창고로 쌓아 둘 수 있는 양을 묶는다 → 남는 자원은 쌓지 못하고 바꿔야 한다.
  3. 시작 거점에 따른 부족 → 남의 기후를 치는 침략이 비싸진다. 설원은 방어, 사막은 빠른 공격 온대는 빠른 훈련.

## 0. 인게임 좌상단 정보 개편 (도트 아이콘)

뒤 단계에서 자원 한도·부족·무역 상태가 더해지기 전에, 지금 글자만 있는 좌상단 정보를 다른 UI(커피·말풍선 아이콘, 버튼)와 같은
도트 스타일의 **아이콘 + 숫자**로 바꾼다.

### 0-1. 지금 (`web/src/game/hud.ts` `update`)
```
식량 160 (+0.5)   목재 160 (+0.3)   석재 40 (+0.0)   유황 12 (+0.3)   병사 7   굶주림!
봄  농사 ×0.6   낮   ×1   일시정지
F1: 조작 설명
```

### 0-2. 바뀐 모습
```
[밀] 160 +0.5   [통나무] 160 +0.3   [돌] 40 +0.0   [유황] 12 +0.3   [투구] 7
[꽃] 봄 · 농사 ×0.6   [해] 낮   ▶ ×1
F1 조작 설명
```
- **자원 칩**: 아이콘 + 가진 양 (굵게) + 1초 수입 (작게, 늘면 연두 / 줄면 붉은색 / 0이면 흐리게).
  - 유황은 지금처럼 가졌거나 나기 시작했을 때만.
  - 굶주림: 식량 숫자가 붉게 깜빡이고 칩 옆에 작은 [굶주림] 표시.
- **둘째 줄**: 계절 아이콘(봄 꽃 / 여름 해 / 가을 단풍 / 겨울 눈송이) + 이름 + 농사 배율, 시각 아이콘(낮 해 / 밤 달 / 해질녘·새벽),
  속도 (▶ ×1, ▶▶ ×2, ▶▶▶ ×4), 일시정지면 ❚❚ 일시정지.
- **셋째 줄** (PC만): `F1` 키 모양 + 조작 설명 (설명 창의 키 그림과 같은 모양).
- **PC 마우스를 올리면**: 칩마다 짧은 설명 ("목재 · 1초에 +0.3 · 벌목장과 거점에서").
- **모바일**: 한 줄로 (자원 칩 + 계절·시각 아이콘만), 아이콘·글자 조금 작게, 수입은 숫자 아래 작게.

### 0-3. 아이콘
- 16×16 도트 SVG (`shape-rendering="crispEdges"`), 지금 `ui/coffee.ts`의 커피잔·로비의 말풍선과 같은 그리기 방식.
  밀 이삭(식량), 통나무 단면(목재), 돌덩이(석재), 노란 결정(유황), 투구(병사), 계절 넷, 해·달, 속도.
- 색은 지형 팔레트에서 (지금 HUD의 금빛 글자·어두운 반투명 바탕과 어울리게), 바깥에 1점 어두운 테두리로 어떤 지형 위에서도 보이게.
- `web/src/ui/icons.ts` (새)에 모아 두고, 나중에 건물 비용 (아래 막대, 마우스 올림 설명의 "목재 50")에도 같은 아이콘을 쓴다.

### 0-4. 뒤 단계를 위한 자리
- 칩 아래 얇은 **한도 게이지** 자리 (2단계 창고에서 채운다: 가득 차면 숫자 색).
- 칩 줄 끝에 부족 표시 자리 (5단계: ❄ / ☀ / 🌿).

### 0-5. 구현 메모
- 좌상단을 한 번만 DOM으로 만들고 매 프레임 숫자 글자만 바꾼다 (지금처럼 매번 `textContent`로 통째로 다시 쓰지 않는다).
- 가림 검사(`panels()`)는 그대로 이 상자를 쓴다.
- PC·모바일 화면 그림으로 확인 (낮·밤, 겨울, 굶주림, 유황 있음/없음).

## 1. 자원 조정

- **자원지 수 ×0.8**: 식량·목재·석재·유황·물고기 자원지 목표 개수를 지금의 0.8배로 (`sim/sites.py`의 목표·`MIN_FLOOR`·
  `SNOW_WOOD_PER`·물고기 기대 개수). 섬마다 목재 최소 보장(`WOOD_ISLAND_BIG`)과 시작 섬의 식량 조건은 그대로.
- **석재 기본 지급 늘리기**: 시작 자원 `START_RES` (160, 160, 40) → **(160, 160, 120)**.
  석재 자원지가 먼 곳에서 시작해도 첫 건물들을 지을 수 있게.
- **목재를 조금 더 중요하게, 석재도 꼭 쓰이게**: 건물 비용을 목재와 석재로 나누되 목재를 약간 더 많이 받는다
  (건물 전체 합으로 목재 : 석재 ≈ 1.45 : 1, 지금은 석재가 거의 안 쓰인다). 처음에 꼭 지어야 하는 채석장은 목재만 받아
  석재가 바닥나도 막히지 않게 한다. 석재 수요가 늘어나는 만큼 채석장 생산을 조금 올린다.

## 2. 자원 한도 (창고 없음: 거점·자원 건물이 창고를 겸한다)

> 바뀜: 처음엔 창고 건물이 있었으나 없앴다. 한도는 자원마다 따로.

- 한도 (자원마다: 식량·목재·석재·유황) = 기본 `STORE_BASE` 200 + 다 지은 거점마다 모든 자원 +`STORE_HALL` 50
  + 다 지은 자원 건물마다 그 자원 +`STORE_SITE` 25 (농장 식량, 벌목장 목재, 채석장 석재, 유황 채취장 유황).
- 한도는 자원 건물에서 들어오는 생산에만 건다: 한도에 닿으면 더 모이지 않는다. 개발 명령·선물로 받아 넘게 가진 것은 깎지 않는다 (약탈은 받는 쪽 한도까지). HUD 자원 칩마다 그 자원의 한도 게이지.
- 나눠 보관과 약탈: 자원 k는 한도에 이바지한 비율대로 그 건물들에 나뉘어 있다 (기본 몫은 어디에도 없어 빼앗기지 않는다).
  거점·자원 건물이 무너지면 그 몫 (가진 양 × 그 건물이 늘린 한도 / 그 자원의 한도)을 마지막으로 친 나라가 가져간다.
- 규칙은 `sim/storage.py` 한 곳, 테스트 `tests/test_storage.py`. 마지막으로 친 나라는 전투 커널이 건물마다 기록한다 (`Buildings.last`).
- 건물 말풍선: 거점·자원 건물에 보관된 자원 (그 건물이 늘린 한도 중 지금 찬 양).

## 4. 부족 (시작 거점 기준)

### 4-1. 판정
- 판을 시작할 때 모든 나라(사람·AI) 하나씩, **시작 거점 자리**로 한 번 정한다 (그 뒤로 바뀌지 않는다).
- 시작 거점 둘레 **20칸**의 육지 중:
  - 설원(봄·가을에도 눈)·얼음·툰드라가 **40% 이상** → **설원 혹은 툰드라**
  - 사막·모래언덕이 **40% 이상** → **사막**
  - 둘 다면 비율이 큰 쪽, 둘 다 아니면 → **온대**
- `sim/tribes.py` (새): 판정 함수 하나. `World`가 나라마다 `tribe`를 들고, 상태로 화면에 보낸다.
  설정 화면·대기실 미리보기도 같은 함수로 시작 자리마다 부족을 표시한다 (❄ 설원 / ☀ 사막 / 🌿 온대).
- **AI 의지 통일**: `sim/ai.py`의 `dragon_tribes`(지금: 둘레 8칸 기준) = 설원 부족 + 둥지에 가장 가까운 나라 하나,
  `tortoise_tribes` = 사막 부족 + 사막에 가장 가까운 나라 하나.
- 튜토리얼은 온대로 고정.

### 4-2. 기후 지역과 적용 대상
- **설원 지역**: 고정 설원(봄·가을에도 눈)·얼음·툰드라. 겨울에만 눈이 덮이는 땅은 아니다. <- 아니 툰드라 지역도 설원으로 치고 적용해.
- **사막 지역**: 사막·모래언덕.
- **병사 유닛만** (보병, 궁수, 창기병, 기마궁수): 어느 거점에서 나왔든, 동맹에게 받았든 **나라의 부족**을 따른다.
  용기사·바위거북·배는 기후의 보너스도 불이익도 받지 않는다.

### 4-3. 특성

| | 설원 (방어) | 사막 (빠른 공격) | 온대 |
|---|---|---|---|
| 강점 | 설원 지역에서 받는 피해 ×0.85, 설원에서 눈 때문에 느려지지 않는다 (눈 덮인 칸은 눈 아래 땅, 만년설·얼음은 고산 초원 빠르기) | 설원이 아닌 지역 어디서나 공격력 ×1.2, 사막 더위를 받지 않는다 (갈증은 모든 부족이 받는다) | 병사 훈련 시간 ×0.85 |
| 사막 지역에서 | 이동 ×0.85, 더위 확률 피해, 갈증 (먹는 식량 ×1.2) | 갈증 (먹는 식량 ×1.2) | 이동 ×0.85, 더위 확률 피해, 갈증 (먹는 식량 ×1.2) |
| 설원 지역에서 | — | 이동 ×0.85, 동상 확률 피해 | 이동 ×0.85, 동상 확률 피해 |
| 길들이기 | 바위거북 ×1.5 시간 | 드래곤 ×1.25 시간 | — |

### 4-4. 확률 피해 (더위·동상)
- 불리한 기후 지역의 병사마다 **3초에 한 번, 50% 확률**로 최대 체력의 **2%** 피해 (보병 0.8, 궁수 0.5).
  여럿이 들어가면 고르게 깎인다 (1분에 약 20%): 상대 기후에서 체력이 깎인다는 불이익을, 병사마다 다른 순간에 맞는 모습으로 보인다.
- **하한**: 기후 피해만으로는 최대 체력의 **30%** 아래로 떨어지지 않는다 (기후는 약하게 만들 뿐, 죽이는 것은 적이다).
  - 비교: 거점 곁 회복이 초당 0.6이라 보병은 집 곁에서 금방 회복한다. 오래 머무는 원정군만 눈에 띄게 약해진다.
  - 이동 ×0.85와 함께, 설원 침공군은 도착할 때 대략 체력 80~90%로 싸우게 된다 (설원 방어 ×0.7과 겹쳐 침공이 확실히 불리).
- 맞을 때 병사 위에 짧은 점 효과: 동상 = 하늘색 눈송이 점, 더위 = 주황 아지랑이 점 (정수 점 크기, 0.3초).

### 4-5. 화면
- HUD 내 나라 이름 옆에 부족 표시, 다른 나라 거점 → 외교 창에 그 나라의 부족.
- 판 시작 몇 초: "❄ 설원 부족: 설원에서 강하고, 사막에서 약합니다" 한 줄.
- 게임 방법에 '부족과 기후' 항목.

## 6. AI

- **창고**: 어느 자원이든 한도의 85%를 넘으면 창고를 짓는다 (거점 곁, 적과 먼 쪽).
- **부족**: 설원 AI는 망루·화염탑을 더, 사막 지역 목표는 뒤로. 사막 AI는 일찍 치고, 설원 지역 목표는 피한다.
  길을 고를 때 불리한 기후 지역을 오래 지나지 않는 쪽을 조금 더 좋아한다.
