# 멀티 플레이 구현 계획

> 상태: 계획 (아직 구현 안 함). 단계마다 끝나면 이 문서의 체크를 갱신한다.

## 0. 원칙: 게임은 나라만 안다

- **게임(World)은 "나라들"만 안다.** 어떤 나라를 사람이 움직이는지 AI가 움직이는지는 모른다. 0번 나라도 다른 나라와 똑같다.
- **나라를 움직이는 것은 바깥의 "조종자"다.** 판(GameSession)이 나라마다 조종자를 하나씩 붙인다:
  - 사람 조종자 (Seat): 접속 하나 — 그 나라로 명령을 보내고, 그 나라의 눈으로 알림·외교·상태를 받는다.
  - AI 조종자 (Bot): 지금 `sim/ai.py`의 Bot — 그 나라로 생각하고 명령한다.
  - 조종자 없음: 사람이 끊겨 떠난 나라. 병사·건물은 그대로 있고 아무도 새 명령을 내리지 않는다.
- **싱글과 멀티는 같은 구조다.** 싱글 = 사람 조종자 1 + AI 조종자들, 멀티 = 사람 조종자 N + AI 조종자들.
  둘의 차이는 "사람이 1명이냐 여럿이냐"에서 나오는 규칙뿐이다 (아래 1장의 속도·일시정지).
- 사람이 몇 번 나라를 맡든 상관없다 (싱글도 0번에 고정하지 않는다: 색·자리 순서대로 나라 번호가 정해지고, 사람은 그중 하나).

## 1. 정해진 것

| 항목 | 결정 |
|---|---|
| 인원 | 한 판 최대 8나라 (사람 + AI). 사람 수에 따라 AI 수를 정해 2~8나라 |
| 속도·일시정지 | **사람이 1명일 때만** 쓸 수 있다 (= 싱글). 사람이 2명 이상이면 속도 1배 고정, 일시정지 없음 |
| 아무도 없을 때 | 접속한 사람이 한 명도 없으면 판을 멈춘다 (싱글에서 끊기면 멈추는 지금 동작이 이 규칙에서 저절로 나온다) |
| 접속이 끊긴 나라 | 30초 동안 다시 접속을 기다린다 (다른 사람이 있으면 판은 멈추지 않는다). 그 뒤에도 안 오면 그 나라는 "조종자 없음": 병사·건물을 **그대로 둔다** (AI가 맡지 않는다). 모두에게 "OO의 접속이 끊겼습니다" 알림만. 다른 사람들이 알아서 쳐서 차지한다. 판이 끝나기 전에 그 사람이 돌아오면 같은 나라로 이어서 한다 |
| 진 사람 | 관전으로 넘어간다 (계속 볼 수 있다, 명령은 못 한다). [나가기] 버튼으로 언제든 로비로 |
| 판 끝 | **게임(World)이 판정: 나라가 하나만 남을 때까지** (사람이든 AI든, 동맹과 상관없이: 동맹끼리 남아도 끝까지 싸운다). 남은 한 나라가 승리. 30초 넘게 끊긴 나라("조종자 없음", `Nation.idle`)는 남은 나라로 세지 않는다. 진 사람은 관전하다 알아서 나가고, 사람이 모두 나가면 판을 서버에서 지운다 (싱글도 같다) |
| 방 비밀번호 | 보안용이 아니라 "방 코드"에 가깝다: 방장이 정한 짧은 글자를 그대로 저장하고 그대로 비교한다 (해시·잠금 횟수 제한 없음) |

## 2. 화면 흐름

```
로비 ─┬─ [싱글 플레이] ─→ 게임 설정 (지금 화면) ─→ 게임
      └─ [멀티 플레이] ─→ 방 목록 ─┬─ 방 누르기 (비밀번호가 있으면 입력) ─→ 대기실
                                  ├─ [코드로 입장] (6자리) ───────────────→ 대기실
                                  └─ [새 방 만들기] ─→ 방 설정 ─────────────→ 대기실 (방장)
대기실 ─(방장 [시작])─→ 게임 ─(지면)─→ 관전 ─[나가기]─→ 로비
                       └─(끝나면)─→ 결과 ─→ 대기실로 돌아가기 / 나가기
```

싱글 플레이도 속으로는 "사람 1명짜리 방"을 만들어 바로 시작한다 (방 목록에는 안 보인다). 그래서 게임 화면·서버 경로는 싱글과 멀티가 같다.

### 2.1 로비
- 지금 [게임 시작] 버튼을 [싱글 플레이]로 바꾸고, 아래에 [멀티 플레이] 버튼을 더한다. [게임 방법], [앱으로 설치]는 그대로.

### 2.2 방 목록 (멀티 플레이)
- 위: 열린 방 목록. 한 줄에 방 이름, 방장, 인원(사람 3/정원 5 · AI 2), 지도 크기, 비밀번호가 있으면 자물쇠. 몇 초마다 새로 고친다.
  대기 중인 방만 보인다 (시작한 판은 목록에서 빠진다).
- 아래: [코드로 입장하기] (6자리 입력 창), [새 방 만들기], [뒤로].

### 2.3 방 설정 (새 방 만들기)
- 지금 게임 설정 화면(`web/src/menu/setup.ts`)을 그대로 쓰고 아래를 더한다:
  - 방 이름, 정원 (사람 2~8), 비밀번호 (선택), AI 수 (사람 정원 + AI ≤ 8), 시작 위치 방식 (각자 고르기 / 무작위).
  - 난이도, 시작 계절, 지도 (프리셋·크기·시드·고급 설정)는 지금 항목 그대로.
- [방 만들기] → 지도를 미리 준비하기 시작하고 대기실로.

### 2.4 대기실
- 왼쪽: 방 이름, **입장 코드 (복사 버튼)**, 게임 설정 요약 (방장은 여기서 바로 바꿀 수 있다), 참가자 목록 (색, 이름, 준비 ✓, 방장 표시, AI 자리).
- 오른쪽: 지금 설정 화면의 **지도 약도** + 나라별 시작 자리 표시 (드래곤 둥지·유황 표시도 그대로).
  - 각자 고르기: 약도를 눌러 내 시작 자리를 고른다 (다른 사람 자리와 너무 가깝거나 못 쓰는 땅이면 거절).
  - 무작위: 서버가 정한 배치를 보여 준다.
- 아래: [준비] / [나가기], 방장만 [시작] (모두 준비했을 때).
- 지도가 아직 만들어지는 중이면 진행 상황을 보여 주고 [시작]을 막는다.

### 2.5 게임 화면
- 싱글·멀티 같은 화면. 사람이 2명 이상인 판에서만:
  - 속도 버튼·마침표 키·일시정지(P)·F5(새 판)를 숨긴다 (서버도 무시한다).
  - 오른쪽 위 나라 목록에 사람 표시, 끊긴 나라에 "끊김".
- 메뉴: [항복] (확인 후), [나가기].
- 관전: 진 뒤에는 화면을 자유롭게 움직이며 볼 수 있다. 명령·건설 버튼은 숨긴다. 위에 "관전 중 · [나가기]".
- 브라우저는 서버가 알려 준 "내 나라 번호"(`start`의 `me`)로만 내 것을 가린다 (지금도 `st.info.me`를 쓴다 — 0번 가정이 남은 곳만 고친다).

## 3. 서버 구조

```
WebSocket ─→ RoomManager ─→ Room (대기실: 참가자, 설정)
                              └─(시작)→ GameSession (판 하나 = 스레드 하나)
                                         ├─ World (나라들만 안다)
                                         └─ 조종자: 나라 번호 → Seat (사람) | Bot (AI) | 없음
```

- **World** (`sim/world.py`): 나라 목록, 규칙, 한 걸음 진행. 사람·AI를 모른다.
  - 지금 World 안에 있는 `self.bots`와 "AI는 돌아가며 생각한다" 부분을 밖(GameSession)으로 옮긴다.
    World는 조종자들이 낸 명령을 받아 처리하기만 한다.
  - 알림: `say(text, to=nid)` — 받는 나라를 붙여 쌓는다 (`to=None`이면 모두에게). 누가 읽을지는 조종자가 정한다.
  - 패배·판 끝: World가 판정한다 (거점과 병사를 모두 잃으면 패배, 나라가 하나만 남으면 끝 `phase='over'`, `winner`). 조종자 없는 나라는 `Nation.idle`로 표시되어 세지 않는다.
- **조종자** (`server/seats.py` 또는 `sim/control.py`, 새로):
  - `Bot`: 지금 `sim/ai.py` 그대로. 자기 나라 번호로만 판단·명령.
  - `Seat`: 접속(send), 나라 번호, `PlayerCommands(world, nid)`, `StateEncoder` (바뀐 것만 보내는 기준이 접속마다 다르다), 알림 읽은 위치, 외교 상태 보낸 버전, 끊긴 시각, 관전 여부.
- **GameSession** (`server/session.py`): World 하나 + 나라별 조종자. 걸음마다
  1. 각 Seat가 받은 명령을 그 나라로 처리한다.
  2. Bot들이 돌아가며 생각한다 (지금처럼 걸음마다 하나씩).
  3. World를 한 걸음 진행한다 (속도·일시정지는 사람이 1명일 때만, 접속한 사람이 0명이면 멈춤).
  4. 각 Seat에게 상태·그 나라 알림·그 나라 외교 상태를 보낸다.
  5. 사람 나라마다 결과 매기기 (Match: 진 사람 = 관전, 판 끝에 남은 나라 = 승리).
- **Room** (`server/rooms.py`, 새로): 번호, 입장 코드 6자리, 이름, 방장, 정원, 비밀번호 (그대로, 없으면 빈칸), 설정(지도·AI 수·난이도·계절·시작 방식), 참가자(이름, 색, 고른 자리, 준비), 상태(대기/진행/끝).
  - 방장이 나가면 다음 사람이 방장. 대기실에 아무도 없으면 방을 지운다.
  - 싱글 플레이 = 사람 1명짜리 방을 만들어 바로 시작.
- **다시 접속**: 지금의 `resume(sid)`를 `resume(room, seat 토큰)`으로. 끊긴 지 30초 안이면 "다시 접속", 그 뒤라도 판이 끝나기 전이면 같은 나라로 돌아온다.

## 4. "0번 = 사람" 가정 걷어내기 (1단계)

지금 코드는 "사람 = 0번 나라"를 곳곳에서 가정한다. 1단계 시작 때 정확한 목록을 만들고 하나씩 지운다 (대략 아래 파일들, 50~60곳).

| 파일 | 지금 | 바꿀 것 |
|---|---|---|
| `sim/world.py` | `nations[0]`이 사람 (`Nation(..., player=True)`, 이름 '나'), `say()`는 0번 나라용, 0번 기준 승패, World가 Bot을 만든다 | 나라들은 모두 같다 (`player` 표시 없음, 이름은 바깥에서), `say(text, to=nid)`, 나라마다 패배만 판정, Bot 생성·생각 차례는 GameSession으로 |
| `sim/wildlife.py`, `sim/boats.py`, `sim/companions.py`, `sim/firetower.py` | `if own == 0: w.say(...)` | `w.say(..., to=own)` (조건 없이: 누가 읽을지는 조종자가) |
| `sim/diplomacy.py` | 0번 나라에게만 알림, 이름 '나', `state_for(0)` | 받는 나라 알림, 모든 나라를 이름으로, 나라마다 `state_for(nid)` |
| `sim/commands.py` | `PlayerCommands(world, 0)` | Seat마다 `PlayerCommands(world, nid)` (안은 이미 nid로 걸러진다) |
| `sim/ai.py` | `Bot(i)` for i in 1..n (World가 만듦) | GameSession이 AI 조종 나라마다 `Bot(nid)` |
| `sim/spawn.py` | 0번 나라 자리를 먼저 (`player_spot`) | "자리를 고른 나라들"의 자리를 먼저, 나머지 무작위 |
| `server/session.py` | 접속 하나 = 0번 나라, 일시정지·속도, 끊기면 멈춤 | 조종자 표 (Seat 여럿 + Bot들), 속도·일시정지는 사람 1명일 때만, 접속한 사람이 0명이면 멈춤 |
| `server/protocol.py` | 접속 하나에 인코더 하나 | Seat마다 인코더 (먼저 이대로, 느리면 "한 번 계산해 여럿에게"로 최적화) |
| `server/app.py` | `/ws`의 첫 메시지 `join` / `resume` | `room_*` 메시지, 방 목록 HTTP. 싱글의 `join`은 "사람 1명 방 만들고 바로 시작"으로 |
| 브라우저 (`web/src`) | 대부분 `st.info.me`를 쓴다 | 0번을 직접 쓰는 곳이 남았는지 찾아 `me`로 (예: 알림·외교 표시) |

## 5. 주고받는 메시지 (추가분)

HTTP
- `GET /api/rooms` → `[{id, name, host, humans, cap, bots, size, locked}]` (대기 중인 방만)

WebSocket (첫 메시지)
- `{t:'join', map, options}` — 싱글 (지금 그대로: 서버가 사람 1명 방을 만들어 바로 시작)
- `{t:'room_create', name, password?, cap, bots, start_mode, setup:{지금 게임 설정 값}, player:{name, color}}`
- `{t:'room_join', id | code, password?, player:{name, color}}`
- `{t:'resume', room, token}` (끊겼다 돌아옴 — 싱글·멀티 같음)

대기실 (브라우저 → 서버)
- `{t:'room_ready', on}` · `{t:'room_spot', y, x}` (각자 고르기) · `{t:'room_color', color}`
- 방장만: `{t:'room_setup', ...바뀐 설정}` · `{t:'room_kick', seat}` · `{t:'room_start'}`
- `{t:'room_leave'}`

대기실 (서버 → 브라우저)
- `{t:'room', id, code, name, host, setup, seats:[{name, color, ready, spot, me, ai}], map_status}` (바뀔 때마다 전체)
- `{t:'room_error', error}` (비밀번호 틀림, 방이 가득 참, 자리 겹침 …)
- `{t:'start', ...지금 start 정보, me: 내 나라 번호, humans: 사람 수, token}` → 그다음은 지금 게임과 같다

게임 중 (추가)
- 브라우저 → 서버: `{t:'surrender'}`
- 서버 → 브라우저: `{t:'seat', nid, state: 'away'|'back'|'gone'|'lost'}` (나라 목록 표시, 알림), `{t:'spectate'}` (내가 졌다)

## 6. 판 규칙

- 속도·일시정지·새 판(F5): 사람이 1명인 판에서만. 2명 이상이면 서버가 무시한다.
- 접속한 사람이 0명이면 판을 멈춘다 (싱글에서 끊긴 경우).
- 끊김 (사람이 2명 이상인 판):
  1. 끊긴 순간: 모두에게 "OO의 연결이 끊겼습니다 (30초 기다립니다)". 그 나라 병사·건물은 하던 일만 계속한다.
  2. 30초 안에 돌아오면: "OO이 돌아왔습니다".
  3. 30초가 지나면: "OO의 접속이 끊겼습니다". 그 나라는 조종자 없음 — 병사·건물은 그대로 (훈련 대기열은 끝까지), 새 명령 없음.
     판이 끝나기 전에 그 사람이 돌아오면 그대로 이어서 한다.
- 패배: 거점과 병사를 모두 잃으면 (지금 규칙) 그 나라의 사람은 관전으로. [항복]도 같은 처리 (항복하면 그 나라의 남은 건물은 지금 패배처럼 허물어진다).
- 판 끝: 1장의 "판 끝" — 나라가 하나만 남으면 (끊겨 떠난 나라는 빼고) 그 나라의 승리. 동맹끼리 남아도 끝나지 않는다.
  - 지금 코드의 "남은 나라가 모두 내 동맹이면 함께 승리" 규칙 (`sim/world.py` `_census`)은 1단계에서 지운다.
  - 진 사람은 관전하며 끝까지 볼 수 있다 (싱글도: 지면 바로 끝나지 않고 관전으로, 언제든 [나가기]).
  - 접속한 사람이 모두 나가면 판은 멈췄다가 정리된다 (아무도 안 보는 AI끼리의 판을 돌리지 않는다).
  - 결과 화면 → 싱글은 [다시]/[로비로], 멀티는 [대기실로]/[나가기].
- 외교: 상대가 사람이든 AI든 같은 메시지 (요청·수락·연장·파기·자원·병력). 받는 쪽이 AI면 Bot이 판단하고, 사람이면 그 사람 화면 위 가운데에 수락 알림이 뜬다.

## 7.1 모든 단계가 끝난 뒤 사용자와 다시 정할 것

- **판 삭제 시점** (정함): 멀티에서 모두 메뉴로 스스로 나갔으면 (끝난 판, 사람이 다 져서 AI만 남은 판, 하는 중에 모두 떠난 판) 바로 지운다.
  한 명이라도 연결이 끊겨 나간 것이면 다시 접속을 기다리는 시간(`RESUME_SECONDS`, 60초) 뒤에 지운다. 싱글은 늘 60초 기다린다.

## 8. 위험과 대응

| 위험 | 대응 |
|---|---|
| 1단계에서 "0번 = 사람" 가정을 놓쳐 남의 알림·외교가 보임 | 바꿀 곳을 목록으로 만들어 지우며 진행 · 사람을 0번이 아닌 나라에 두고 시험 · 가짜 2인 테스트 |
| 사람 수만큼 상태를 따로 계산해 서버가 느려짐 | 처음엔 Seat마다 인코더, 측정 후 "공통 부분 한 번 계산" 최적화 |
| 대기 중인 방이 쌓임 | 대기실이 비면 바로 지우고, 오래(예: 30분) 시작하지 않은 방도 지운다 |
| 비밀번호 | 보안이 목적이 아니다 (한 판용 방 코드). 그대로 저장·비교, 방 목록에는 자물쇠만 |
| 끊긴 사람의 나라가 오래 남아 판이 늘어짐 | 그 나라는 조종자 없이 가만히 있어 쳐서 차지할 수 있다 · 판 끝 판정에서 남은 나라로 세지 않는다 |
| 동맹끼리만 남으면 판이 늘어짐 | 규칙상 끝까지 싸워야 한다 (동맹 기간이 끝나면 풀리고, 깨면 배신자). 필요하면 나중에 "마지막 둘이 동맹이면 동맹이 안 맺어진다" 같은 보완을 검토 |
| 기존 테스트가 "0번 = 사람"을 가정함 (`tests/*`) | 1단계에서 테스트도 "사람 나라 번호"를 받아 쓰게 고친다 |
